Foundation

WHAT IS NMAP?

Nmap (Network Mapper) is an open-source tool used for network exploration and security auditing. It helps you discover hosts, identify open ports, detect services, and gather valuable information about your network attack surface.

OPEN

Accepting Connections

An application is actively listening for TCP connections or UDP packets. Open ports represent the primary attack surface to examine for service enumeration and vulnerability detection.

FILTERED

Firewall Blocked

A packet filter, firewall rule, or network security appliance is dropping probes before they reach the port. Nmap cannot determine whether the port is open or closed due to packet loss.

CLOSED

Host Responsive

The port is accessible and receives probes, but no application is listening. The host responds with an immediate TCP RST packet, confirming the host is online and reachable.

Extensibility

GO BEYOND PORT SCANNING

The Nmap Scripting Engine (NSE) unlocks deep vulnerability inspection, SSL certificate parsing, cryptographic algorithm audits, and web discovery.

--script=http-title

Web Discovery

Fetches and indexes HTML page titles from HTTP/HTTPS endpoints for rapid asset identification.

--script=ssl-cert

SSL/TLS Auditing

Extracts subject names, issuer authorities, expiration timestamps, and SAN extensions.

--script=ssh2-enum-algos

SSH Cipher Audit

Enumerates key exchange (KEX) algorithms and flags weak or deprecated cryptographic ciphers.

--script=http-headers

Security Headers

Inspects HTTP response headers to verify HSTS, CSP, and X-Content-Type protection.

Triage

SECURITY FINDINGS

Automated rule engines transform raw scan observations into structured findings categorized across standard security severity levels.

High Severity

Cleartext administrative protocols (Telnet, unencrypted FTP), vulnerable software versions with known exploits, or exposed database ports without auth.

Medium Severity

Unencrypted HTTP web services without TLS certificates, weak SSH cryptographic key-exchange algorithms, or out-of-date web servers.

Low Severity

Verbose service banner disclosure, missing security hardening headers, or non-standard port listeners with default configurations.

Informational

Standard service inventory observations, verified SSH server availability, active DNS listeners, and baseline topology mapping.
