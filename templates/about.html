Safe Lab Constraints

By default, this web application restricts scans to private subnet IP ranges (RFC 1918) and local loopback coordinates:

  • 127.0.0.1 / ::1 (Local Host)
  • 10.0.0.0/8 (Class A Private Network)
  • 172.16.0.0/12 (Class B Private Network)
  • 192.168.0.0/16 (Class C Private Network)

This rule prevents unauthorized outbound scans to public networks.

Viva Cheat Sheet (College Q&A)

The application uses Python's subprocess.Popen class with arguments passed as a structured array rather than a single command string. The parameters shell=False and strict sanitization are implemented. Users cannot type arbitrary command syntax, eliminating SQL Injection or Command Injection risks.

The application initiates Nmap with the -oX switch, generating scan outcomes in structured XML formats. Python's xml.etree.ElementTree module parses this XML to extract host status, ports, services, OS versions, and script results before inserting them into SQLite.

A rule-based Finding Analyzer scans version numbers and services. For example, detecting plaintext HTTP on port 80 triggers a "Low" finding recommending encryption, while discovering outdated server software versions triggers "Medium" or "High" observations.
